# Outpostcraft Demo

Playable Windows demo of **Outpostcraft**, a co-op top-down survival template for Unreal Engine 5.6, 5.7 and 5.8,
in C++ with every system open to Blueprint. It is the template's own sample game, packaged as a Shipping build with
UE 5.8: loot and build by day, hold the outpost against the horde by night, for 1 to 4 players.

**Download:** [OutpostcraftDemo_Win64.zip](https://github.com/filipetessaro/outpostcraft-demo/releases/latest/download/OutpostcraftDemo_Win64.zip)
(230 MB). No engine needed: unzip and run `Outpostcraft.exe`.

Choose New outpost to play alone (it starts on Easy), or host and join over a local network. A second controller
adds a second player on the same screen. The controls are in `HOW_TO_PLAY.txt`, next to the game.

Docs: https://apps.tessaroapps.com/outpostcraft/docs/
